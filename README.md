# HW3 – Stock Strategy Classifier (ONNX on GitHub Pages)

Predicts the best of three investment strategies (DCA_Buy_Hold, Drawdown60, Year_Sept_April) for a stock based on its sector, industry, and eight financial performance and risk metrics calculated from 2016 to 2026.

Input Features (10 total):

Sector (e.g., Energy)

Industry (e.g., Railroads)

10Y Return (Annualized) (%)

Risk / Return Rank (1Y)

Sharpe Ratio

Sortino Ratio

Omega Ratio

Martin Ratio

Calmar Ratio

Ulcer Index (%)
